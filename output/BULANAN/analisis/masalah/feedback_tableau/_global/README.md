# Upload Folder Global

Kalau kamu nemu masalah lain yang belum tercatat di `solusi_masalah.md`, upload SS/file ke folder ini dengan penamaan jelas:

- `bab{N}_ws{M}_{deskripsi}.png` — untuk screenshot
- `bab{N}_ws{M}_{deskripsi}.csv` — untuk export data

Contoh:
- `bab3_ws3_trend_aneh.png`
- `bab4_ws5_legend_kosong.png`

Lalu kasih tahu aku file-nya beserta deskripsi singkat masalahnya.
